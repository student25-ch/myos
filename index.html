项目简介

这是从零手写的极简x86操作系统，由汇编语言编写。包含引导扇区 bootloader 和基础内核，可在 QEMU 模拟器中启动运行。

目录结构

myos/
├── boot.asm        # 引导扇区(512字节，0xAA55标记)
├── kernel.asm      # 内核汇编源文件
├── .gitignore
├── README.md
└── index.html      # GitHub Pages页面

构建命令（手动编译）

nasm boot.asm -f bin -o boot.bin
nasm kernel.asm -f bin -o kernel.bin

fsutil file createnew pad.bin 1474560
copy /b boot.bin + kernel.bin + pad.bin myos.img

"QEMU路径\qemu-system-i386.exe" -L "QEMU路径" -drive format=raw,file=myos.img,if=floppy
